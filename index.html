Introduction

Hi! My name is Danzel Yap. This is why I build.

It started in the backyard, doing yard work with my mom. That was my first taste of building something with my hands — and of doing it together, as a team. That feeling never left me. What draws me to construction isn't the concrete or the scale; it's watching a massive project come together through sheer community — hundreds of people, every trade and every crew, all pulling in the same direction until a building stands where there was nothing but dirt. Getting to be part of that is the whole reason I'm here.

So I build for them — six live apps my crew runs every day on the $2B LA Convention Center, from tool tracking to pour tracking, unified in one command center. We're just getting started.

A-100The ProcessField first · Polish last · Repeat

How I build.

Field first, polish last — then do it again. Every tool starts with a problem I watched cost someone an afternoon.

01

Work hands-on in the field.

Find what really needs improving. If a foreman can't use it with one gloved hand and no English, it doesn't work.

02

Design around what we have.

Build the framework from our existing systems — Sheets, Firebase, whatever the crew already trusts.

03

Build one core function.

Create the single thing it has to do well, then take it straight to the field.

04

Test on site. Fix what breaks.

See if it survives 6 AM on a real jobsite. Fix what breaks before adding anything.

05

Make it sharp.

Build a clean, modern front end and add the features that make crews want to open it.

06

Repeat and scale.

Then do it all again — one more problem, one more tool — and scale across the job.

S-000The System — Five Apps, One HubModel-Derived · One Login

The Command Center.

Concrete work runs on a handful of questions: what is scheduled, what is poured, what is installed, where the tools went — and whether any of it matches the structure on the drawings. I built a production app for each one, then the hub that answers all of them on a single screen.

SY-20 · Schedule
SuperYap
Look-ahead builder with a working-day engine and company-format PDF/Excel export. Replaced an afternoon of weekly spreadsheet surgery.
CUP-02 · Pours
CUP Dashboard
Live pour tracking — footing map, truck log, embed checklists, inspection ticker. Replaced a spreadsheet, a clipboard, and walkie-talkies.
EY-18 · Embeds
EmbedYap
299 embeds, 75 types, extracted from plan PDFs with computer vision and tracked as live pins on the map. Replaced a highlighter and a memory.
TT-00 · Tools
Tool Tracker
Assets-as-truth registry with on-site verification. The old way — printouts from the legacy system — lost roughly 65 tools in a single cycle.
YG-24 · The Model
YapGrid
The foundation modelled in the browser from the project's own IFC, with the reinforcing generated from the structural schedules. The hub's map is drawn from this.
CC-22 · The Hub
Command Center
One role-aware login: the schedule, pour status, every embed, RFIs, submittals, inspections, tools and today's crew on a single live map — each layer deep-linking into its app. Since August 2026 that map is generated from the structural model, so every shape on it is a real member. And it issues the paperwork the job runs on. The superintendent runs the 6 AM tailgate from this screen.

S-050The Model — YapGridDerived From The Model · Not Traced
New · August 2026

Maximizing value
from a 3D model.

Every app above ran on a plan someone had traced off a PDF. So I took the project's own Revit IFC export — all of the concrete, and not one reinforcing bar — and built a browser 3D model of the foundation, generating every bar from the structural schedules and the typical details.

It takes off concrete, formwork and a bar schedule instead of counting by hand, prints region sheets on the company title block, and checks itself: modelled volumes agree with the schedules' own dimensions to within 0.1%. It also found grade beam bars running straight through piles, before anyone had to find them in the field. The Command Center map is now drawn from this, not from a tracing.
